# LASER - Lab Search & Recommendation System

A platform to help students discover and connect with research labs at SKKU.


## 📦 Repositories

### [laser-fe](https://github.com/laser-skku/laser-fe)
React frontend deployed on Railway. Search labs by department, view professor profiles, and get AI-powered lab recommendations.

### [laser-be](https://github.com/laser-skku/laser-be)
FastAPI backend deployed on AWS EC2. Handles lab data, paper information, and AI recommendation endpoints.

### [laser-proxy-server](https://github.com/laser-skku/laser-proxy-server)
Simple Express.js proxy to bridge HTTPS frontend with HTTP backend (solves mixed-content issues).

### [laser-crawling](https://github.com/laser-skku/laser-crawling)
Python scripts to crawl and collect professor information, lab details, paper abstracts, and homepage links from various sources.

### [laser-skku-overview](https://github.com/laser-skku/laser-skku-overview)
Documentation repo with project details, system design, and implementation notes.
